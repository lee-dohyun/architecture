# docs

`architecture` 저장소의 세부 작업/설계 문서를 모아두는 폴더.

- `README.md`/`CLAUDE.md`에는 저장소 전체를 이해하는 데 필요한 요약만 남기고, 특정 기능/변경/이슈에 대한 상세 기록은 이 폴더에 파일로 추가한다.
- 파일명 컨벤션: `YYYY-MM-DD-주제.md` (예: `2026-08-01-keycloak-realm-migration.md`)
- 작업이 커서 별도 문서가 필요할 때만 추가 — 한두 줄짜리는 커밋 메시지나 PR 설명으로 충분함

## 전 저장소 공통 표준
- [COMMENT_STANDARDS.md](COMMENT_STANDARDS.md) — 코드 주석(JSDoc/JavaDoc)
- [USER_GUIDE_STANDARD.md](USER_GUIDE_STANDARD.md) — 사용자 설명서(화면을 쓰는 사람용) 양식과 작성 원칙. 설명서 자체는 각 저장소 `docs/user-guide/` 에 둔다
